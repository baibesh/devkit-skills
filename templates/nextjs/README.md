# Next.js agent rules

`AGENTS.md` here is the block that `next dev` (Next.js 16.3+) writes into a project. It was generated by `create-next-app@16.4.3` + `next dev` on 2026-10-29.

It tells the agent to read the version-matched docs bundled in `node_modules/next/dist/docs/` instead of relying on training data.

- Next.js 16.3+: nothing to do, `next dev` creates and maintains the file. Commit it.
- Older projects: copy `AGENTS.md` to the project root after upgrading, or run `npx @next/codemod@latest upgrade`.
- Claude Code reads `CLAUDE.md`, so add a `CLAUDE.md` containing the single line `@AGENTS.md`.
