# spring-boot

Team conventions and testing guide for Spring Boot 4 on Java 21-25.

| Skill | Purpose |
|---|---|
| `spring-boot-conventions` | Layout, injection, DTOs, REST + Problem Details, JPA, config, Flyway, observability |
| `spring-boot-testing` | Unit, slice and integration tests, Testcontainers, ArchUnit |

Install: `claude plugin install spring-boot@devkit-skills`. For deeper references also install `spring-boot-community@devkit-skills`.
