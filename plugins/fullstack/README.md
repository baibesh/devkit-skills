# fullstack

Cross-stack skills for Spring Boot backends with TypeScript frontends.

| Skill | Purpose |
|---|---|
| `api-contract` | OpenAPI-first contract: springdoc, generated TS clients, Problem Details, CI drift checks |
| `review-checklist` | Severity-ordered code review for backend, frontend and security |
| `fullstack-feature` | Contract-first workflow for features spanning API and UI |

Install: `claude plugin install fullstack@devkit-skills`.
