# frontend

Framework-agnostic TypeScript skills for Angular, React and Next.js projects.

| Skill | Purpose |
|---|---|
| `typescript-conventions` | Strict tsconfig, ESLint + Prettier, module layout, boundary validation, async and errors |
| `frontend-testing` | Vitest + Testing Library, Angular Vitest builder, MSW, Playwright |

Install: `claude plugin install frontend@devkit-skills`, plus the framework plugin (`angular`, `react` or `nextjs`).
