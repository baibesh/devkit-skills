# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-29

### Added

- Claude Code marketplace `devkit-skills` with 7 plugins.
- Referenced upstream plugins: `angular` (angular/skills), `react` (vercel-labs/agent-skills), `nextjs` (vercel/next.js), `spring-boot-community` (sivaprasadreddy/sivalabs-agent-skills).
- Own plugins: `spring-boot` (`spring-boot-conventions`, `spring-boot-testing`), `frontend` (`typescript-conventions`, `frontend-testing`), `fullstack` (`api-contract`, `review-checklist`, `fullstack-feature`).
- `npx skills` support via `skills.sh.json`, Codex marketplace for own plugins.
- Next.js `AGENTS.md` template generated by Next.js 16.4.3.
- CI: skill and manifest validation, version-bump check, install smoke test, link check.
